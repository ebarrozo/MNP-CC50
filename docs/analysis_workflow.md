# Analysis workflow

## 1. Raw plate preprocessing and QC

**Script:** `scripts/01_preprocess_plate_data.R`

Inputs:
- `metadata/key_plate_layout.xlsx`
- 60 BMG MARS workbooks in `data/raw/`

The script validates the expected plate map, parses experimental and control wells, applies corrected final concentrations (0.2, 2, 20 µg/mL), calculates plate-specific media/methanol normalization, performs plate-level QC, averages technical triplicates, and estimates replicate-level CC50 values.

Primary QC requires methanol > media. SSMD is retained as an assay-separation diagnostic, with an SSMD ≥1 subset used as a sensitivity analysis.

Primary output directory: `results/v5_2/`.

## 2. Final CC50 statistical models

**Script:** `scripts/02_fit_cc50_models.R`

Inputs:
- QC-valid replicate-level CC50 values from step 1
- strict-SSMD sensitivity CC50 values
- plate-QC summary

Analyses:
- primary additive LMM;
- BeWo-referenced cell-line contrasts;
- all pairwise cell-line contrasts;
- polymer, size, and duration contrasts;
- censoring-aware ordinal mixed model;
- strict SSMD ≥1 LMM sensitivity;
- separate secondary cell line × polymer, cell line × duration, and cell line × size models.

Primary output directory: `results/v6_3/`.

## 3–6. Manuscript Table 1, Figures 2–3, and Supplementary Table S1

**Scripts:**

- `04_make_figure2.R`

## 7. No-cell particle-fluorescence diagnostics

**Script:** `scripts/07_particle_interference_diagnostics.R`

Inputs:
- `data/no_cell/08.26.26-EthD1_mnponly.xlsx`
- original QC-valid cell-containing normalized wells from step 1

The script dynamically locates the A–H plate block in the no-cell workbook, applies the same polymer/size/dose map, and calculates particle-associated excess fluorescence relative to no-cell media.

Important: the no-cell control experiment did not include the wash steps used in the cell-containing assay. These measurements therefore characterize potential optical interference and are not directly subtracted from cell-containing fluorescence.

Diagnostics include Spearman associations:
- overall across 24 unique polymer × size × dose conditions;
- by cell line;
- by exposure duration;
- within dose;
- within cell line × exposure duration.

Output directory: `results/interference/v6_5/`.

## 8. Final condition-level optical-interference models

**Script:** `scripts/08_particle_interference_condition_models.R`

Using the 24 unique polymer × size × dose conditions, the final regression models test:

```text
mean apparent death ~ particle-only fluorescence + polymer + size + dose
median apparent death ~ particle-only fluorescence + polymer + size + dose
```

Particle-only fluorescence is standardized, so the reported coefficient is the change in apparent percent cell death per 1-SD increase in particle-associated fluorescence. HC3 robust standard errors are calculated when `sandwich` and `lmtest` are installed.

Output directory: `results/interference/v6_6/`.

## 9. Supplementary Table S2

**Script:** `scripts/09_make_supplementary_table_s2.R`

The workbook contains:
- S2A: no-cell particle-associated fluorescence by condition;
- S2B: condition-level and stratified Spearman diagnostics;
- S2C: final condition-level regressions and HC3 sensitivity.

Output: `outputs/Supplementary_Table_S2_ParticleInterference.xlsx`.

## Analyses intentionally excluded from the public workflow

An exploratory one-for-one subtraction of no-cell fluorescence from cell-containing wells was evaluated during method development. It is not included because it assumes that particle-derived fluorescence is linearly additive and transferable between no-cell and cell-containing wells. That assumption was not established, and direct subtraction produced large shifts in censoring and particle-size effects. The manuscript therefore uses the no-cell experiment as an optical-interference diagnostic rather than a quantitative correction.
